Режим данных

Все операции выполняются in-memory. Изменения не сохраняются в localStorage и не мутируют backend-таблицы.

In-Memory No Persistence

Роли и доступ

Доступны роли: Администратор (полный доступ) и Сотрудник (личный кабинет). Переключение через экран входа.

RBAC Sandbox Auth

API статус

Backend API не подключен в данном sandbox-режиме. Используются мок-данные для демонстрации UX/UI.

Mock Data No API
