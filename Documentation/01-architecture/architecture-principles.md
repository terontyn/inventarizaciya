# Architecture Principles

1. Каждая фича сначала проектируется, потом кодируется.
2. Каждый сервис владеет своей БД.
3. Прямой доступ к БД другого сервиса запрещен.
4. Взаимодействие сервисов — через API и/или events.
5. Tenant isolation обязателен во всех сервисах.
6. Критические действия попадают в audit.
7. API должен быть versioned.
8. Решения уровня платформы и архитектуры фиксируются в ADR.
