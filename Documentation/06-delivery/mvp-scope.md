## In Scope
- tenant / org structure
- users / roles / departments / branches / locations
- asset CRUD
- базовое назначение актива
- audit ключевых действий

## Out of Scope
- software licensing
- maintenance
- full ticket workflow
- advanced reporting
- external integrations

## First Release Goal
За 1-й релиз компания может:
- завести пользователя
- завести актив
- назначить актив сотруднику
- видеть текущий статус и историю
