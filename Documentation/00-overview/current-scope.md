# Текущая область проекта
Семь Spring Boot сервисов реализуют ограниченный IT asset management pilot. Asset/user расширены рабочими API обращений, типов, SIM-карт и картриджей. Склад, обслуживание, ПО, тикеты и сводки имеют отдельные контракты.
Вымышленный demo использует настоящие asset/user API и локальную H2. Production требует PostgreSQL и доверенной аутентификации перед X-Authenticated headers. Выбор пользователя в pilot UI не является входом в защищённый SaaS.
См. [миграции](../../docs/migrations.md) и [демонстрацию](../../docs/demo.md).
